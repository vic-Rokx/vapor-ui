Menu or Select?

A menu does something: each item is an action, run once when picked, and the button keeps its own label. Edit, Duplicate, Delete.

A select chooses a value: the choice stays, the button shows it, and a form reads it. A country, a sort order, a size. If the button should show what was picked, use a Select.

Behaviour

What the menu does for you.

Behaviour

Opening

A click, Enter or Space on the button opens it with the focus on the first item; Down opens it there too, Up at the last.

Keyboard

Up and Down move between items, wrapping round; Home and End go to the ends; a letter goes to the next item starting with it. Enter or Space picks.

Pointer

Moving over an item highlights it, as the keys do; a click picks it.

Closing

A pick, Escape, Tab or a click outside. The focus goes back to the button.

Screen readers

The button says it opens a menu and whether it's open. The menu has role=menu and its label, each item role=menuitem, and disabled ones aria-disabled.
