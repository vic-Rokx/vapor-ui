API Reference

Item Structure

Define the data and render functions for each panel.

.{ .title = "Label", .description = "Extended text content...", .trigger = MyHeaderFn, .content = MyBodyFn }

Initialization

Pass a slice of AccordionItem structs to the init method.

var accordion = Accordion.init(&.{ item1, item2 });

Render Functions

Your custom functions receive a pointer to the current item.

fn MyTrigger(item: *Accordion.AccordionItem) void { ... }
