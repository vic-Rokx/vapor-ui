charts-ui ⇒

charts-ui

A collection of ready-to-use chart components built on top of Vapor. From basic charts to rich data displays, copy and paste into your apps.

Usage

Set a chart up once in your page's init, then render it. It fills its parent's width. Hover it to read the values at a point.

Behaviour

What the chart does for you.

Behaviour

Tooltip

Over the plot it names the nearest x and lists each series' value there; on a pie, the slice's value and share. It hides over the margins, sits beside the point on the side with room, and never takes a click.

Zoom

Drag to zoom; double-click or Reset zoom to go back. Reset zoom sits outside the plot, so pointing at it hides the tooltip and pressing it starts no drag.

Legend

Buttons that hide and show their series, with aria-pressed, so a keyboard and a screen reader can use them too. The axes fit what is shown.

Size

Follows its parent's width as the page resizes.
