API Reference

Setup

Render the tooltip layer once, in your layout; every tooltip shows there.

Opaque.TooltipLayer();

Tooltip.simple

A text trigger with a text tooltip above it.

Tooltip.simple(trigger_text, tooltip_text); Tooltip.simpleWithPosition(trigger_text, tooltip_text, .bottom);

Tooltip.create

Your own trigger, and optionally your own content.

Tooltip.create(.{ .content = "Text", .position = .top }) .Trigger(myTrigger, .{args}) .Component(myContent, .{args}) // optional .end();

Behaviour

Shows after a short hover or on keyboard focus; hides on leave, blur or Escape. The popup has role=tooltip.
