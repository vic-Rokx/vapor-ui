Options

Passed to render, each time; the carousel keeps only which slide it's on.

Options

id

[]const u8

Required. Names the carousel, so it keeps its slide across renders. One per carousel.

count

usize

Required. How many slides you render, for the dots and the ends.

viewport_width

f32

= 480

The width shown, in px. Never wider than its container: on a narrow screen the slide is cropped.

viewport_height

f32

= 280

The height shown, in px.

stride

f32

= 496

From one slide's start to the next: slide width plus gap. Render your slides that wide.

loop

bool

= true

Wrap from the last slide to the first, and back.

show_arrows

bool

= true

Previous and next buttons over the slides.

show_dots

bool

= true

A dot per slide below, to jump to it.

swipe_threshold

f32

= 60

How far, in px, a drag must go to change slide.

transition_ms

u32

= 350

How long the slide takes to settle.

Behaviour

What the carousel does for you.

Behaviour

Swiping

Drag with a mouse or finger and the slides follow. Past swipe_threshold it moves one slide on release; a shorter drag springs back. Vertical swipes still scroll the page.

Keyboard

The arrows and dots are buttons: Tab reaches them, Enter or Space uses them.

Screen readers

The arrows are named Previous slide and Next slide, the dots Go to slide 1, 2…

One slide

With a single slide there are no arrows or dots.
