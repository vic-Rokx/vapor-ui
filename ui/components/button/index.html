Defaults

The look it starts with. Each one is a builder call you can make again to change it.

Defaults

background

= .transparentize(.hex("#F5F5F5"), 0.2)

A light wash that works on either theme.

border

= .round(.palette(.border_color_light), .all(12))

A thin line, in the theme's border colour.

padding

= .xy(10, 8)

Room around the content.

layout

= .x_between_center

Children in a row, centred vertically, 8px apart.

width, height

= .fit

As big as its content.

shadow

A faint inset edge and a drop shadow, which go away on hover.

hover

Darkens 5% and grows 1%, over 100ms.

Behaviour

What the button does for you.

Behaviour

Keyboard

It's a real button: Tab reaches it, Enter or Space clicks it.

Screen readers

Its text names it. A button with only an icon needs .ariaLabel.

Busy

Mark it disabled and busy with .a11y, and give it a handler that does nothing, as Loading does.
