Select(T)

?*const fn (*Self, *Item) void

= null

Called with the item clicked.

trigger

[]const u8

The trigger's text until something is picked.

trigger_component

?*const fn (*Self) void

= null

Draws the trigger instead, inside the button that opens the list.

trigger_label

?[]const u8

= null

Names the trigger for screen readers; needed when your trigger has no text, like an icon.

is_detached

bool

= false

Set it when you render the trigger and the list apart.

max_height

f32

= 256

The list's height before it scrolls; 512 with more than 12 items.

height

Sizing

= .px(36)

The trigger's height, and each item's.

border

Border

= .round(.transparentize(.black, 0.2), .all(12))

The list's border.

Behaviour

What the select does for you.

Behaviour

Picking

Click an item to pick it; click the picked item again to clear it.

Closing

Escape, or a click outside the list.

Keyboard

The trigger and items are buttons: Tab reaches them, Enter or Space uses them.

Screen readers

The trigger says it opens a listbox and whether it's open. The list has role=listbox; each item has role=option and reports aria-selected.
