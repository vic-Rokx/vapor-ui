Behaviour

What both do for you.

Behaviour

Screen readers

Both have role=progressbar, named Progress, and report their value from 0 to 100, also after updateProgress.

Animation

updateProgress glides to the new value in 300ms.

Over time

Call updateProgress from a Vapor.lib.loopInterval, as Animated Progress Bar does.
