API Reference

ProgressBar Initialization

Create a progress bar with custom dimensions and colors.

var bar = ProgressBar.init(allocator, .{ .width = 128, // Width in pixels .height = 6, // Height in pixels .color = .palette(.tint), // Fill color .background = .transparentize(...), // Track color });

ProgressCircle Initialization

Create a circular progress indicator with configurable options.

var circle = ProgressCircle.init(allocator, .{ .size = 120, // Diameter in pixels .stroke_width = 10, // Ring thickness .track_color = .palette(.highlight_color), .color = .palette(.text_color), // Progress color .clockwise = true, // Direction .show_label = true, // Show percentage .label_font_size = 12, // Label size .label_color = .palette(.text_color), });

Setting Progress

Set or update the progress value (0.0 to 1.0).

// Set initial progress (no animation) bar.setProgress(0.5); // 50% circle.setProgress(0.75); // 75% // Update progress (with animation) bar.updateProgress(0.8); // Animate to 80% circle.updateProgress(0.9); // Animate to 90%

Render Methods

Render the progress component.

bar.render(); // Render the progress bar circle.render(); // Render the progress circle

Animation with Intervals

Create smooth progress animations using Vapor intervals.

// Start animation loop (60ms interval) Vapor.lib.loopInterval("my-progress", 60, updateFn, .{}); fn updateFn() void { if (bar.progress >= 1.0) { Vapor.lib.cancelTimeout("my-progress"); return; } bar.updateProgress(bar.progress + 0.01); }
