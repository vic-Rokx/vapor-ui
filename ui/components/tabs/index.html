API Reference

NavBar

The tabs keep their state under the tag, so the selection survives rerenders.

const index = Tabs.NavBar("tag", &.{ "One", "Two" });

create

Returns the Tabs for the tag, to configure before rendering.

const index = Tabs.create("tag", names).default(selected).onClick(onTab).render();

Trigger

Renders each tab with your function; active is true for the selected one.

fn TabTrigger(tabs: *Tabs, name: []const u8, active: bool) void { ... }

Keyboard

Left and Right move between tabs, Home and End jump to the first and last.
