What a segmented control does for you.

Behaviour

Keyboard

One Tab stop, on the chosen option; the arrow keys move the choice and wrap round, Home and End go to the ends.

Screen readers

A radio group named by label, each option a radio that reads checked or not.

Or Tabs?

Segmented changes a setting; for a choice that shows another panel, use Tabs.
